# Scholar Assistant · 全新界面设计方案「Atlas」

> **UI Designer（像素君）** · 设计方案 v1.0 · 2026-07-22
> 配套可预览概念稿：`docs/_concepts/atlas-concept.html`
> 本文档为「全新用户界面」设计总纲，与既有 `frontend-consistency-audit.md`（一致性收口）互为补充：审计是"修旧"，本方案是"换新方向"。

---

## 0. 设计目标与对旧方案的突破

### 0.1 核心诉求（来自需求）
1. 美观、现代，符合 2026 主流趋势；
2. 交互简洁直观，新用户零学习成本上手；
3. 遵循常见操作习惯（导航位置、按钮层级、信息密度符合预期）；
4. **视觉层次 / 色彩 / 布局相对旧方案有明显突破，避免雷同**；
5. 输出完整方案：关键页面布局 + 组件规范 + 交互逻辑；
6. 整份报告经一轮优化打磨。

### 0.2 旧方案「研墨」的特征（待突破对象）
| 维度 | 旧方案现状（实测令牌） |
|---|---|
| 温度 | **暖色纸墨**：暗 `#14130f` 暖近黑、亮 `#FAF8F3` 暖纸白、边框 `#E8E1D3` 暖灰 |
| 强调色 | `#5b6cff` 偏紫蓝 + 渐变 `#8b74e6`；品牌朱红 `#C8503A`（vermilion） |
| 身份手法 | **笔触 / 墨韵 / 印章纹理**（v-ink-bleed / v-brush-stroke / 朱印） |
| 字体 | Inter + Noto Sans SC；衬线仅 EB Garamond 点缀 |
| 布局 | 左侧栏（`--shell-sidebar-width:236px`）+ 居中版心（`--page-width:880px`） |
| 密度 | 偏紧凑，靠边框与墨色分层 |

### 0.3 「Atlas」新方向的 4 个突破点
1. **温度翻转：暖 → 冷**。`#FAF8F3` 暖纸白 → `#F5F7FA` 冷调工作室灰；`#14130f` 暖黑 → `#0E1117` 冷调深石板。整体"安静、精确、现代 SaaS"，与旧方案的"文房"气质彻底拉开。
2. **身份手法翻转：纹理 → 排版**。弃用笔触/印章，改用**衬线 Display 字体（Newsreader / Source Serif 4）+ 大留白 + 精确层级**作为新记忆点——更耐看、更"学术"、不廉价。
3. **布局翻转：单栏版心 → 三区工作区**。左侧 72px 图标轨（遵循"左导航"直觉）+ 顶部命令条（⌘K 全局搜索）+ 中央画布 + 右侧可收起情境面板。信息密度与专注度同时优化。
4. **强调色翻转：紫蓝 → 冷钴蓝**，并**移除朱红品牌色**（改为克制的钴蓝辉光作为完成态签名）。配色更克制、对比更清晰。

> 注：新方向仍保留"隐私优先学术写作"的产品内核，只是换了一套更现代、更冷静、更易上手的"外衣"。是否保留朱红作为可选品牌强调，见 §2.4 备选。

## 1. 设计原则（Design Principles）

- **P1 清晰优先（Clarity）**：任何时刻用户都知道"我在哪、能做什么、刚发生了什么"。层级靠排版与留白，不靠堆边框。
- **P2 安静退后（Deference）**：UI 是舞台，内容是主角。控件默认低存在感，hover/激活才显形。
- **P3 深度可信（Depth）**：用冷调柔和阴影 + 微妙 elevation 表达层级，而非到处玻璃模糊（玻璃会拖累长文可读性，违背学术场景）。
- **P4 一致性（Consistency）**：所有交互走同一套令牌与原语；一处定义，处处复用。
- **P5 即时反馈（Feedback）**：每个动作都有可见结果（toast / 进度 / 状态），杜绝静默 no-op。
- **P6 容错（Forgiveness）**：非破坏式导航 + 明确的撤销（Agent 操作、删除均有 undo）。
- **P7 可达性硬指标（WCAG 2.1 AA）**：对比度、键盘、焦点管理非协商。

### 2.2 旧 → 新 色彩对比（突破点一览）

| 角色 | 旧（暖） | 新（冷） | 说明 |
|---|---|---|---|
| 暗背景 | `#14130f` 暖黑 | `#0E1117` 冷石板 | 去掉纸黄，更"屏幕感" |
| 亮背景 | `#FAF8F3` 暖纸 | `#F5F7FA` 冷灰白 | 去暖，提净 |
| 边框 | `#E8E1D3` 暖灰 | `#E3E8F0` 冷灰 | 与冷表面同调 |
| 强调 | `#5b6cff` 紫蓝 | `#2F6FED` 冷钴蓝 | 更"产品/精确" |
| 品牌 | `#C8503A` 朱红 | 移除（改用钴蓝辉光） | 去纹理身份 |
| 主文本(暗) | `#e4e4ea` | `#E8ECF2` | 略冷提亮 |
| 阴影 | 暖调重影 | 冷调柔影 | 更轻、更现代 |

### 2.3 对比度（WCAG AA）
- 正文 `--t-0` on `--surface-1`：暗 15.8:1 / 亮 14.2:1（远超 4.5:1）
- 次文本 `--t-1` on surface：暗 7.1:1 / 亮 6.4:1（达标）
- 强调按钮白字 on `--accent`：亮 4.6:1 / 暗 4.8:1（达标，临界故 hover 加深）
- 弱文本 `--t-3` 仅用于非必要标注，不承载正文

### 2.4 备选强调色（如需更大胆）
若希望与旧紫蓝差异更极端，可换 **Teal `#0E8C7F`** 或 **Violet `#7C5CFF`**；二者与冷中性均协调。默认采用钴蓝（最稳、最"学术 SaaS"）。

## 3. 字体与排版（Typography）

### 3.1 字体族
- **Display（标题/品牌）**：`Newsreader` / `Source Serif 4`（衬线， editorial 气质）——**新身份核心**，替代旧方案的笔触纹理。
- **UI / 正文**：`Inter` / system-ui（与旧一致，保证可读性）。
- **CJK**：`Noto Sans SC` / `PingFang SC`。
- **Mono**：`JetBrains Mono`（代码、JSONL 会话）。

### 3.2 字阶（Type Scale，1.2 比例，舒适而不拥挤）

| Token | 尺寸 | 用途 | 字重 | 行高 |
|---|---|---|---|---|
| `--text-display` | 40px | 欢迎页主标题 | 600 (serif) | 1.12 |
| `--text-3xl` | 30px | 页面标题 | 600 | 1.2 |
| `--text-2xl` | 24px | 区块标题 | 600 | 1.3 |
| `--text-xl` | 19px | 卡片标题 | 600 | 1.4 |
| `--text-lg` | 16px | 小标题/强调 | 600 | 1.5 |
| `--text-base` | 14px | 正文/UI | 400/500 | 1.55 |
| `--text-sm` | 13px | 次要 UI | 400 | 1.5 |
| `--text-xs` | 12px | 标注/元信息 | 500 | 1.4 |

### 3.3 排版工艺（CJK/Latin 混合）
- 启用 `text-spacing-trim: trim-start`（CJK 标点挤压）、`font-feature-settings: "tnum"`（数字等宽，用于进度/统计）。
- 长文 `line-height: 1.7`，段间距 `--s-4`，阅读版心 `max-width: 72ch`。
- Display 衬线用于"欢迎/项目名/章节标题"，UI 正文用 Inter——**用字体本身区分层级，而非靠颜色/边框**。

## 4. 间距、栅格与布局（Layout）

### 4.1 间距系统
4px 基准，scale：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。组件内边距默认 `--s-4`，区块间距 `--s-5`~`--s-6`，页面留白慷慨。

### 4.2 应用外壳：三区工作区（Three-Zone Workspace）
遵循"左导航 + 顶动作 + 内容居中"的通用直觉：

```
┌──┬───────────────────────────────────────────────┬──────────┐
│  │  顶栏 56px：项目面包屑 │ ⌘K 全局搜索 │ 动作+账户   │          │
│  │───────────────────────────────────────────────│  右侧情境 │
│  │                                                 │  面板     │
│  │            中央画布（编辑器/翻译/导图）          │ (320–360) │
│  │                                                 │  可收起   │
│  │                                                 │          │
└──┴───────────────────────────────────────────────┴──────────┘
 72px 图标轨
```

- **左图标轨 72px**：Library / Editor / Translate / MindMap / Agent 五个主模式（icon + tooltip），激活项用左侧 3px 钴蓝竖条 + 软辉光。符合"导航在左"习惯。
- **顶栏 56px**：左=项目名+面包屑；中=⌘K 搜索（占 40% 宽，常驻）；右=主操作（New / Export）+ 主题切换 + 账户头像。
- **中央画布**：最大宽度随模式（编辑器 72ch 阅读版心；翻译双栏；导图全幅）。
- **右侧面板**：AI 助手 / 大纲 / 检视器，可一键收起（收起后图标轨右出现细标签）。

### 4.3 信息密度
- 默认**舒适密度**（comfortable）：行高宽松、控件间距 `--s-3`~`--s-4`。
- 提供"紧凑模式"开关（设置内），仅缩小间距与圆角，不改结构。

## 5. 高程与动效（Elevation & Motion）

### 5.1 高程
3 级柔和冷调阴影（§2.1）。**默认不玻璃模糊**；仅命令面板/弹窗的遮罩用 `backdrop-filter: blur(8px)` 且 `bg: rgba(14,17,23,0.32)`，克制使用。

### 5.2 动效原则
- 仅用 `transform` / `opacity`（保 60fps）。
- 微交互用弹簧缓动 `--ease-spring`（0.22,1,0.36,1），时长 140–300ms。
- 列表/卡片进场用 stagger 40ms 错峰。
- **尊重 `prefers-reduced-motion`**：全部降级为瞬时。

### 5.3 签名交互（替代旧笔触）
- **完成态辉光**：AI 生成完成 / 导出成功 → 目标处一抹钴蓝辉光 + 弹簧对勾（非朱印）。
- **命令面板**：⌘K 自顶部弹性展开，结果原地高亮。
- **视图切换**：中央画布用 200ms 淡入+8px 上移（统一，避免旧方案双套动画漂移）。
- **专注模式（Focus Mode）**：写作时顶栏/右栏渐隐，鼠标移动或 ⌘ 召回——学术写作最被低估的体面（旧方案缺失）。

## 6. 组件库规范（Component Specs）

> 所有组件基于令牌；交互态统一：`hover` 抬升/变色、`active` 回弹、`focus-visible` 钴蓝环、`disabled` 降透明度+禁指针。

### 6.1 按钮（Button）
| Variant | 用途 | 样式 |
|---|---|---|
| Primary | 主操作（Export/Generate） | `--accent` 底，白字，hover 加深+`--elevation-2` |
| Secondary | 次操作 | surface-2 底 + border，hover surface-3 |
| Ghost | 低存在感（工具栏） | 透明，hover 浅底 |
| Danger | 删除/危险 | `--danger` 底或 danger 文字 |
| Icon | 纯图标（收起/设置） | 40×40，hover 圆底 |

尺寸：`sm 28px` / `md 34px` / `lg 40px`；圆角 `--r-md`；加载态显示 spinner 并禁用。

### 6.2 输入（Input / Textarea / Select）
- 高度 34px（md），圆角 `--r-md`，border 默认 `--border`；
- `:focus` → border `--accent` + `box-shadow: 0 0 0 3px var(--accent-ring)`；
- 错误态 border `--danger` + 下方红字提示；placeholder `--t-3`。

### 6.3 卡片（Card）
- 默认 surface-1 + border + `--elevation-1`，圆角 `--r-lg`；
- `interactive`：hover `--elevation-2` + 1px 上移（transition 200ms）；
- 内边距 `--s-5`；标题用 `--text-xl`。

### 6.4 导航（Nav / Icon Rail / Tabs）
- 图标轨激活：左 3px 钴蓝条 + `--accent-soft` 底；
- 顶部 Tabs：底部 2px 钴蓝下划线滑动；
- 面包屑：可点击，当前项 `--t-0` 其余 `--t-2`。

### 6.5 反馈（Toast / Modal / Tooltip）
- **Toast**：右下角，4 类语义色，3px 左色条，自动消失 4s，可堆叠；
- **Modal**：遮罩 `blur(8px)` + 居中卡，`role="dialog"` + **焦点陷阱** + Esc 关闭 + 关闭后焦点归还触发元素；
- **Tooltip**：hover/focus 显示，12px，延迟 200ms。

### 6.6 数据展示（Table / List / Badge）
- Table：行高 44px（touch 友好），header `--t-2` 12px 大写字距，行 hover surface-2；
- Badge：圆角 pill，语义色浅底深字；
- Empty State：居中图标 + 一句引导 + 主操作按钮（替代旧空白）。

## 7. 关键页面布局（Key Screens）

### 7.1 欢迎 / 项目库（Welcome · Library）
布局：左图标轨 + 顶栏（含 ⌘K）+ 中央 **bento 网格**。
- 顶部 Hero：衬线 Display 标题"欢迎回来，研究者" + 副标；
- 最近项目：大卡（封面缩略 + 名 + 时间 + 一键打开）；
- 快速操作：New / 导入 PDF / 模板（图标按钮行）；
- 模板区：3–4 张模板卡（论文/综述/笔记）。
- 空状态：首次使用显示"创建第一个项目"主 CTA。

```
┌─┬──────────────── 顶栏 ⌘K ────────────────┐
│ │  Hero(serif)                               │
│ │  [+ New] [导入] [模板]                      │
│ │  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐      │
│ │  │最近1 │ │最近2 │ │最近3 │ │最近4 │  ←bento│
│ │  └──────┘ └──────┘ └──────┘ └──────┘      │
│ │  模板： [论文] [综述] [笔记] [书评]          │
└─┴──────────────────────────────────────────┘
```

### 7.2 编辑器工作区（Editor）— 最高频
三区：图标轨 + 顶栏（项目名 + ⌘K + 导出/专注模式）+ 中央阅读版心 + 右栏（大纲/AI）。
- 中央：Monaco 编辑器，阅读版心 `72ch`，舒适行高；
- 右栏 Tab：**大纲**（可跳转）/ **AI 助手**（对话 + 工具结果）；
- 专注模式：右栏与顶栏渐隐，仅留光标与文本；
- 保存：自动 + 完成时 Toast"已保存"（杜绝旧方案静默）。

### 7.3 翻译视图（Translate）
双栏对照：左原文 / 右译文，顶部进度条（SSE `translate.*`）+ 术语表 chips + 引擎切换（顶栏段控）。
- 进度态：顶部细进度条 + 区块高亮"翻译中"；
- 完成态：右侧出现"导出双语/仅译文"主操作 + 钴蓝辉光。

### 7.4 思维导图（Mind Map）
全幅画布 + 左浮动工具条（添加/布局/缩放）+ 右检视器（节点编辑）。
- 节点增删用 FLIP 平滑过渡（替代旧硬跳/重建）；
- 选中节点：钴蓝描边 + 软辉光。

### 7.5 Agent 面板（Agent / Chat）
右侧面板内嵌对话流：用户气泡右、Agent 左；工具调用折叠卡（可展开看 `tool_result`）；`await_approval` 显示内联审批按钮；流式 `token` 用轻量淡入（**不**用笔触逐字）。
- 操作均有 `undo` 入口；危险操作二次确认。

### 7.6 设置（Settings）
左侧分组（外观/模型/快捷键/隐私）+ 右详情；外观含主题（暗/亮/跟随系统）+ 密度 + 字体；快捷键列出可改绑定。

---

## 8. 交互逻辑与流程（Interaction Logic）

### 8.1 首次上手（降低学习成本）
1. 启动 → 欢迎页（bento）；
2. 首次创建/打开项目 → **3 步引导 tour**（① 左轨切换模式 ② ⌘K 全局搜索 ③ 右栏 AI 助手）；
3. 进入编辑器 → 非阻塞提示"按 ⌘K 随时呼出命令"。

### 8.2 导航模型（统一，修旧审计 N1）
- 单一事实源：图标轨 = 主模式；顶栏面包屑 = 项目/文档层级；
- 切换模式**保留各自状态**（修旧 N3 切导图丢编辑）；
- 关闭项目 → 回到欢迎页（修旧 L3 幽灵标签）。

### 8.3 主操作层级（修旧 N2 静默）
- 主操作固定在顶栏右侧（New/Export），语义明确；
- **每个动作都有反馈**：导出→进度→完成 Toast（不再无提示 no-op）；
- 破坏性操作（删除项目/覆盖）走确认 Modal + undo 5s。

### 8.4 全局命令（⌘K）
- 任意处 ⌘K 打开；支持：跳模式、开项目、跑 Agent、切换主题、查快捷键；
- 结果键盘可达，Enter 执行，Esc 关。

### 8.5 键盘与可达性
- 全功能键盘可达；模态焦点陷阱 + 关闭归还焦点；
- 焦点环统一 `--accent-ring`（修旧 29 文件无焦点环）；
- 列表/表格行 44px 触控目标。

## 9. 无障碍（Accessibility · WCAG 2.1 AA）

- **对比度**：正文 ≥ 4.5:1、大字 ≥ 3:1（§2.3 实测达标）；
- **键盘**：完整可达 + 逻辑 Tab 序 + 可见焦点；
- **屏幕阅读器**：语义标签 + ARIA（`role=dialog/navigation/tablist`）；
- **动效敏感**：`prefers-reduced-motion` 全降级；
- **文本缩放**：布局支持 200% 缩放不破版；
- **触控**：目标 ≥ 44px。

## 10. 响应式（Responsive）

| 断点 | 宽度 | 布局 |
|---|---|---|
| Desktop | ≥1280 | 三区全开（图标轨+顶栏+画布+右栏） |
| Compact | 1024–1279 | 右栏默认收起，按需展开 |
| Tablet | 768–1023 | 图标轨变底栏？否——保留左轨，右栏抽屉化 |
| Mobile | <768 | 单列：顶栏 + 抽屉式导航 + 全宽画布（桌面优先产品的降级，非主场景） |

> Scholar Assistant 以桌面/Web 预览为主，移动为降级而非重设计。

## 11. 设计交接与实施建议（Handoff）

### 11.1 执行顺序（与一致性审计协同）
1. **Phase 0 地基**：全局焦点环 + 亮色断裂修复（沿用 `frontend-consistency-audit.md` P0）——先做，保证不打滑；
2. **Phase 1 换肤**：接入 `Atlas` 令牌（冷色 + 钴蓝 + 衬线 Display），替换旧暖色/朱红；
3. **Phase 2 布局**：三区外壳（图标轨 + 顶栏 ⌘K + 右栏），迁移各视图进新外壳；
4. **Phase 3 动效**：完成态辉光、专注模式、FLIP 导图、⌘K 弹性；
5. **Phase 4 打磨**：bento 欢迎页、空/加载态、引导 tour。

- `npm run typecheck` + `npm run build` 通过；

- 明暗双主题截图对比，确认无不可见/脏边；
- 动效 60fps（DevTools Performance 抽查）；
- 对比度扫描（axe / 手动）AA 通过。

### 11.4 执行优先级（Phase 0 → 4，按风险排序）

| Phase | 内容 | 风险 | 工作量 | 验收信号 |

| **0** | 全局焦点环 + 亮色断裂修复（沿用审计 P0） | 低 | 小 | 29 文件缺口闭合、亮色边框可见 |
